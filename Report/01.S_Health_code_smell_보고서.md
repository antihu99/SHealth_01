## 5. 코드 구조·처리 흐름 요약

### 5.1 클래스 역할

| 클래스 | 역할 |
|--------|------|
| `SHealth` | CSV 로드 → 체중 0 보정 → BMI → 나이대별 4분류 비율 집계 → `getBmiRatio` |
| `SHealthBMI` | `main` — `shealth.dat` 처리 후 콘솔 출력 |
| `SHealthBMITest` | JUnit 5 (실질 TC 없음) |

### 5.2 `calculateBmi` 처리 순서 (요구사항 §7 대조)

```text
[1] shealth.dat 읽기(헤더 스킵) → [2] ages/weights/heights 적재
→ [3] 나이대별 weight=0 평균 보정 → [4] BMI 계산
→ [5] 4분류 카운트 → [6] 나이대별 비율(%) 필드 저장 → return count
```

| 단계 | 요구사항 일치 | 비고 |
|------|---------------|------|
| 파일 읽기·보정·BMI | ✅ | id 미저장, 엣지 예외 존재 |
| 4분류 | △ | BMI=25 미분류 (BUG-01) |
| 비율 집계 | △ | 빈 나이대 시 sum=0 나눗셈 (BUG-02) |

### 5.3 `getBmiRatio(ageClass, type)`

- `ageClass`: 20, 30, 40, 50, 60, 70 (구간 시작값)
- `type`: 100=저체중, 200=정상, 300=과체중, 400=비만
- **24분기 if-else** — 리팩토링 High 우선 대상

## 6. 코드 스멜 분석 결과 (요약)

상세 표는 `docs/01.S_Health_코드스멜_분석보고서.md` §3 참조.

| 우선순위 | 스멜 | 위치 | 위반 원칙 |
|----------|------|------|-----------|
| **High** | Long Method | `calculateBmi` (~100줄) | SRP |
| **High** | God Class | `SHealth` 전체 | SRP, OCP |
| **High** | Duplicate Code | 나이대 루프 3회, 비율 저장 6×4 | DRY |
| **High** | Magic Number | 18.5, 23, 25, 100~400, 10000 | 유지보수 |
| **High** | Switch/분기 폭발 | `getBmiRatio` 24분기 | OCP, DRY |
| **Medium** | Primitive Obsession, Data Clumps | 병렬 배열 4개 + 비율 필드 24개 | 응집도 |
| **Medium** | Mutable Global State | 인스턴스 필드 29개 | 테스트성 |
| **Medium** | Swallowed Exception | `printStackTrace()` | 실패 명시 |

**식별 건수**: 코드 스멜 **16건** (High 6, Medium 5, Low 5).

## 7. 요구사항 대비 잠재 결함 (요약)

| ID | 이슈 | 심각도 | 요구사항 |
|----|------|--------|----------|
| **BUG-01** | BMI = **25** 미분류 (`> 25`만 비만) | High | 비만 ≥ 25 |
| **BUG-02** | 빈 나이대 `sum == 0` 나눗셈 | High | TS-05 |
| **BUG-03** | 구간 전원 weight=0 → `ageCount==0` | High | TS-02 |
| **BUG-04** | `height == 0` → BMI Infinity/NaN | High | TS-01 |
| **BUG-05** | I/O 실패 후 silent 진행 | Medium | TS-06 |

**경계값 검증 권장**: 18.5, 23, 25 및 나이대 19/20, 29/30 (3단계 `@ParameterizedTest`).
