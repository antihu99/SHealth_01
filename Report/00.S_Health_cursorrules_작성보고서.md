## 5. 요구사항 정의서 (`SHealthRequirements.txt`)

### 5.1 작성 근거

- **1차 출처**: `README.md` (개요, 데이터 샘플, BMI 분류 기준)
- **보조 참고**: 기존 `SHealth.java`의 `getBmiRatio(ageClass, type)` 인터페이스
- **형식 참고**: `GildedRoseRequirements.txt` (텍스트 명세 스타일)

### 5.2 핵심 비즈니스 규칙

| 구분 | 규칙 |
|------|------|
| 입력 | `shealth.dat` CSV — `id, age, weight(kg), height(cm)` |
| BMI | `체중(kg) / (키(m))²`, cm → m 변환 |
| 체중 누락 | `weight == 0` → 동일 나이대(10세 구간) 평균 체중 보정 |
| 나이대 | 20, 30, 40, 50, 60, 70 시작 — `[a, a+10)` |
| 분류 | 저체중 ≤18.5 / 정상 &lt;23 / 과체중 &lt;25 / 비만 ≥25 |
| 통계 | 나이대별 4분류 비율(%) |
| 기능 요구 | FR-01 ~ FR-06 |
| 테스트 참고 | TS-01 ~ TS-06 |

### 5.3 처리 흐름

```text
[1] shealth.dat 읽기 → [2] 레코드 적재 → [3] 체중 0 보정
→ [4] BMI 계산 → [5] 분류 → [6] 나이대별 비율 → [7] 조회
```

## 6. `.cursorrules` 작성 내용

### 6.1 설계 원칙

| 원칙 | 설명 |
|------|------|
| Single Source of Truth | 비즈니스 규칙은 `SHealthRequirements.txt` 우선 |
| 실습 단계 정렬 | `작업시나리오` 1~5단계·4단계 기능 개선 범위 반영 |
| 레거시 호환 | `calculateBmi`, `getBmiRatio` public API 유지·테스트 회귀 |
| TDD·리팩토링 | Green 상태에서만 리팩토링, Given-When-Then, `@ParameterizedTest` |
| 최소 변경 | 요청·실패 테스트 범위만 수정, 불필요 문서·설정 추가 금지 |

### 6.2 `.cursorrules` 섹션 구성

| 섹션 | 내용 |
|------|------|
| 역할·참조 문서 | 시니어 Java QA, 문서 우선순위 3단계 |
| 기술 스택 | Java 8, Maven, JUnit 5, Mockito, Hamcrest, ApprovalTests |
| 도메인 개요 | BMI·보정·분류·통계 표 |
| 절대 규칙 | 요구사항 준수, 데이터 계약, API 호환, 범위 제한 |
| 실습 단계 | 1~5단계 표 + 4단계 확장(키 0 보정, 정상 목록, 전체 비율) |
| 테스트 규칙 | GWT, ParameterizedTest, TS-01~06 |
| TDD/리팩토링 | Red-Green-Refactor, 상수화, SRP, `mvn test` |
| 체크리스트 | 8항목 작업 전·후 확인 |

### 6.3 `작업시나리오` 4단계 기능 개선 반영

`.cursorrules`에 향후 AI가 구현할 확장 기능을 명시함:

- **키(height) 0 보정**: 동일 나이대 비-zero 키 평균 적용
- **정상 BMI 사용자 목록**: `18.5 < BMI < 23` 조회
- **전체 사용자 BMI 범주 비율**: 나이대 무관 전체 4분류 비율(%)

## 7. 기존 코드와의 관계

### 7.1 `SHealth.java` 현황 (리팩토링 전)

| 항목 | 내용 |
|------|------|
| 구조 | 단일 클래스에 파일 I/O, 보정, BMI, 통계, 조회 혼재 |
| 코드 스멜 | 고정 배열(10000), 매직 넘버(100/200/300/400), 중복 나이대 루프, 긴 if-else |
| 경계값 | 비만 분류가 `BMI > 25`로 구현 — 명세(`≥25`)와 불일치 가능 (향후 TC로 검증) |

### 7.2 `.cursorrules`가 제어하는 향후 작업

- 1단계: 코드 스멜 분석 보고 (동작 변경 최소)
- 2단계: 네이밍·상수화·함수 추출·DRY
- 3단계: BMI·보정·분류·예외 단위 테스트
- 4단계: SRP 분리 및 확장 기능
- 5단계: 회고 문서
