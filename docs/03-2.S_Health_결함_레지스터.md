| 필드 | 내용 |
|------|------|
| 심각도 | High |
| 상태 | **Test-Locked** (수정 전 TC 갱신 필요) |

| 영향 | 비만 1건 누락, 4분류 합 &lt; 나이대 인원 |

**재현 (GWT)**

- **Given** BMI=25.0인 사용자 1명
- **When** `classifyBmiCategoryIndex(25.0)` 호출
- **Then** 기대(명세): 비만(3); 실제: `-1`

**증거**

```143:156:src/main/java/com/bestreviewer/SHealth.java

        // ...
        if (bmi > BMI_OVERWEIGHT_MAX) {  // 25.0은 false → 비만 미적용

        return -1;
```

- TC: `SHealthBmiClassificationTest.classifyBmiCategoryIndex_boundaryValues` — `"25.0, -1"`

**4단계 대응:** `bmi >= BMI_OVERWEIGHT_MAX` 또는 `else` 분기로 비만 포함; TC-03-02 기대값 변경; 회귀 `SHealthBMITest` 재검토.
