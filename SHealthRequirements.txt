SHealth BMI Requirements Specification
======================================
문서명   : SHealth 요구사항 정의서
프로젝트 : SHealth BMI (Java)
출처     : README.md
작성 목적: 삼성 헬스 수집 데이터 기반 BMI 통계·분류 기능의 요구사항 명세

----------------------------------------------------------------------
1. 개요 (Overview)
----------------------------------------------------------------------

1.1 목적
  삼성 헬스에서 수집된 사용자 건강 데이터를 활용하여,
  나이대(예: 20대, 30대, 40대 등)별로
  저체중 / 정상체중 / 과체중 / 비만 비율(통계)을 계산한다.

1.2 범위
  - 입력 파일(shealth.dat)에서 사용자 데이터를 읽는다.
  - 누락된 체중값을 보정한다.
  - 사용자별 BMI를 계산한다.
  - BMI 기준으로 체형을 분류한다.
  - 나이대별 BMI 분포 비율을 산출한다.

1.3 제약·참고
  - 제공된 기존 코드에는 다양한 코드 품질 문제가 존재한다.
    (리팩토링·테스트 작성 시 별도 품질 개선 활동 대상)
  - 코드 품질 향상을 위해 Java/Python 등에서는
    필요 시 외부 모듈 사용을 허용한다.

----------------------------------------------------------------------
2. 입력 데이터 (Data Specification)
----------------------------------------------------------------------

2.1 파일
  - 파일명 : shealth.dat
  - 형식   : CSV (쉼표 구분)
  - 1행    : 헤더 (id,age,weight,height)

2.2 레코드 필드
  | 순서 | 필드명   | 설명        | 단위 |
  |------|----------|-------------|------|
  | 1    | id       | 사용자 식별자 | -    |
  | 2    | age      | 나이        | 세   |
  | 3    | weight   | 몸무게      | kg   |
  | 4    | height   | 키          | cm   |

2.3 데이터 샘플
  id,age,weight,height
  93705,66,79.5,158.3
  93708,66,53.5,150.2
  93709,75,88.8,151.1
  ... (이하 생략)

2.4 파싱 규칙
  - 헤더 1행은 데이터로 사용하지 않는다.
  - 이후 각 행은 id, age, weight, height 순서로 해석한다.
  - 빈 행 또는 유효 토큰이 없는 행은 처리 종료 조건으로 간주할 수 있다.

----------------------------------------------------------------------
3. BMI 계산 (BMI Calculation)
----------------------------------------------------------------------

3.1 공식
  BMI = 체중(kg) / 키(m)^2

3.2 단위 변환
  - 입력 키(height)는 cm 단위이다.
  - 계산 시 키를 m 단위로 변환한다.
    height(m) = height(cm) / 100

3.2 예시
  - 체중 79.5 kg, 키 158.3 cm
  - BMI = 79.5 / (1.583 * 1.583)

----------------------------------------------------------------------
4. 누락 데이터 보정 (Missing Data Imputation)
----------------------------------------------------------------------

4.1 대상
  - 수집 과정에서 누락된 체중값
  - 체중(weight)이 0인 경우를 누락으로 간주한다.

4.2 보정 규칙
  - 동일 나이대(예: 20대, 30대, 40대 등) 사용자 중
    체중이 0이 아닌 사용자들의 평균 체중을 구한다.
  - 체중이 0인 사용자에게 해당 나이대 평균 체중을 적용한다.

4.3 나이대 구간
  - README 및 기존 구현 기준: 10세 단위 구간
  - 구간 시작 연령: 20, 30, 40, 50, 60, 70
  - 각 구간 [a, a+10) 에 속하는 사용자를 동일 나이대로 본다.
    예) 20대: age >= 20 && age < 30
        30대: age >= 30 && age < 40
        ... 70대: age >= 70 && age < 80

4.4 보정 순서
  - 나이대별 평균 체중 산출 후, 해당 구간 내 weight=0 레코드에 일괄 적용
  - 보정 완료 후 BMI 계산을 수행한다.

4.5 예외·경계 (명시되지 않은 항목)
  - README에는 체중 0 누락만 명시되어 있다.
  - 키(height) 0 누락 보정은 README 본문에 없음 (향후 확장 시 별도 정의 필요).

----------------------------------------------------------------------
5. BMI 분류 기준 (BMI Classification)
----------------------------------------------------------------------

5.1 분류표
  | 분류       | 조건 (README 기준)     |
  |------------|------------------------|
  | 저체중     | BMI <= 18.5            |
  | 정상체중   | 18.5 초과 ~ 23 미만    |
  | 과체중     | 23 이상 ~ 25 미만      |
  | 비만       | 25 이상                |

5.2 경계값 정리
  - 18.5 : 저체중 / 정상체중 경계
  - 23   : 정상체중 / 과체중 경계
  - 25   : 과체중 / 비만 경계

5.3 분류 로직 (의사코드)
  if (BMI <= 18.5)           -> 저체중
  else if (BMI < 23)         -> 정상체중   // 18.5 < BMI < 23
  else if (BMI < 25)         -> 과체중     // 23 <= BMI < 25
  else                       -> 비만       // BMI >= 25

----------------------------------------------------------------------
6. 나이대별 통계 (Age-Group Statistics)
----------------------------------------------------------------------

6.1 목표
  - 각 나이대(20대~70대, 10세 단위)별로
    저체중 / 정상체중 / 과체중 / 비만 사용자 비율(%)을 계산한다.

6.2 산출 지표
  - 나이대별 저체중 비율 (%)
  - 나이대별 정상체중 비율 (%)
  - 나이대별 과체중 비율 (%)
  - 나이대별 비만 비율 (%)

6.3 계산 방법
  - 해당 나이대에 속하는 사용자 수를 분모(sum)로 한다.
  - 각 BMI 분류에 해당하는 사용자 수를 분자로 한다.
  - 비율(%) = (분류별 인원 수 / 나이대 전체 인원 수) * 100

6.4 대상 나이대
  - 20대, 30대, 40대, 50대, 60대, 70대 (구간 시작값 20~70, 10 간격)

6.5 조회 인터페이스 (기존 코드 참고)
  - getBmiRatio(ageClass, type)
    - ageClass : 20, 30, 40, 50, 60, 70 (나이대 시작값)
    - type     : 100=저체중, 200=정상체중, 300=과체중, 400=비만
  - 반환값 : 해당 나이대·분류의 비율(%, double)

----------------------------------------------------------------------
7. 처리 흐름 (Processing Flow)
----------------------------------------------------------------------

  [1] shealth.dat 파일 읽기 (헤더 스킵)
  [2] 사용자 레코드 적재 (id, age, weight, height)
  [3] 나이대별 체중 0 보정 (동일 나이대 평균 체중 적용)
  [4] 사용자별 BMI 계산
  [5] 사용자별 BMI 분류 (저체중/정상/과체중/비만)
  [6] 나이대별 분류 비율(%) 집계
  [7] 결과 조회 (예: getBmiRatio)

----------------------------------------------------------------------
8. 기능 요구사항 목록 (Functional Requirements)
----------------------------------------------------------------------

  FR-01  시스템은 shealth.dat에서 CSV 형식의 사용자 데이터를 읽어야 한다.
  FR-02  시스템은 각 사용자의 BMI를 kg·cm 입력 기준 공식으로 계산해야 한다.
  FR-03  시스템은 체중이 0인 경우 동일 나이대 평균 체중으로 보정해야 한다.
  FR-04  시스템은 BMI를 저체중/정상체중/과체중/비만으로 분류해야 한다.
  FR-05  시스템은 20·30·40·50·60·70대별 BMI 분류 비율(%)을 산출해야 한다.
  FR-06  시스템은 나이대·분류 유형별 비율을 조회할 수 있어야 한다.

----------------------------------------------------------------------
9. 비기능·품질 요구 (Non-Functional / Quality Notes)
----------------------------------------------------------------------

  NFR-01  기존 코드는 코드 스멜·구조적 문제를 포함하므로
          분석·리팩토링·단위 테스트 작성이 권장된다.
  NFR-02  필요 시 표준 라이브러리 또는 외부 모듈 사용 가능.

----------------------------------------------------------------------
10. 테스트 시 고려 시나리오 (Test Scenarios Reference)
----------------------------------------------------------------------

  TS-01  BMI 계산 정확성 (cm→m 변환 포함)
  TS-02  체중 0 보정 — 동일 나이대 평균 적용
  TS-03  BMI 경계값 분류 (18.5, 23, 25 전후)
  TS-04  나이대 구간 경계 (19/20, 29/30 등)
  TS-05  나이대별 비율 합계 및 빈 나이대 처리
  TS-06  파일 없음·형식 오류 등 예외 상황

----------------------------------------------------------------------
11. 용어 정의 (Glossary)
----------------------------------------------------------------------

  BMI      : Body Mass Index, 체질량지수
  나이대   : 10세 단위 연령 구간 (예: 20대 = 20세 이상 30세 미만)
  저체중   : BMI 18.5 이하
  정상체중 : BMI 18.5 초과 23 미만
  과체중   : BMI 23 이상 25 미만
  비만     : BMI 25 이상
